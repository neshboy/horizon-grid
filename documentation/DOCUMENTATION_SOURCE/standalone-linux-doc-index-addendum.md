# Linux Documentation

- **HORIZON_GRID_LINUX_INSTALLATION.pdf** -- Step-by-step guide to installing the horizon-grid_0.2.0_amd64.deb package on Ubuntu 24.04 LTS, Ubuntu 22.04 LTS, or Debian 12, including the required Docker Engine + Compose v2 setup (via Docker's official convenience script) and the terminal setup wizard; intended for system administrators performing a first-time install or reconfiguring an existing one.
- **HORIZON_GRID_LINUX_TECHNICAL_DOCUMENTATION.pdf** -- Reference covering the installed file layout (/opt, /etc, /var/lib, /var/log), the horizon-grid CLI commands, systemd service integration, port bindings, provider/AI configuration, and remove-vs-purge cleanup behavior; intended for administrators and technical staff operating, maintaining, or troubleshooting a deployed instance.
- **HORIZON_GRID_LINUX_QA_REPORT.pdf** -- Results of the end-to-end test pass across all three supported distributions, including the real bugs found and fixed during packaging, the per-distro pass/fail counts with an explanation of the two known test-harness-artifact failures, and the AI-safety and provider-behavior findings observed during live testing; intended for engineering and QA stakeholders evaluating release readiness.
